📦 git add .
含义：暂存所有更改。
作用：把当前目录下所有新建、修改或删除的文件，全部放入一个叫“暂存区（Staging Area）”的临时口袋里。
比喻：把你写好的作业、修改的文件整整齐齐地放进快递包装盒里，准备封口。
🏷 git commit -m '你的提交信息'
含义：提交保存。
作用：把暂存区里的文件正式保存到本地仓库，并生成一个历史记录点。-m 后面单引号里的内容是你的“提交备注”，用来记录这次修改了什么。
比喻：把快递盒子用胶带封好，并在外面贴上一张便签纸（比如写着“修复了登录界面的 Bug”），方便以后查找。
🚚 git push
含义：推送至远端。
作用：将你本地仓库中刚刚保存的记录，上传到网络上的远程代码仓库。
比喻：把这个封好、贴好标签的快
